Panduan Tilawah 2 Muka Sehari

Mushaf Madinah

• Surah Al-Baqarah bermula dari Muka Surat 2 hingga Muka Surat 49 (Jumlah: 48 muka surat).

• Dengan membaca 2 muka surat setiap hari, anda mengambil masa genap 24 hari untuk khatam keseluruhan surah.

• Setiap kad mengandungi nota panduan ayat bagi muka surat tersebut untuk memudahkan anda menyemak bacaan.

• Kemajuan anda akan disimpan secara selamat di dalam peranti ini dan tidak akan hilang walaupun pelayar ditutup.

Cara Dapatkan Link URL Sendiri

Percuma & Ambil Masa 1 Minit

Supaya anda boleh buka link di Google telefon dan tekan Add to Home Screen, anda boleh gunakan tapak percuma Vercel, Tiiny Host, atau GitHub Pages.

Cara Paling Pantas (Tiiny.host):
  1. Tekan butang hijau di bawah: "Salin Semua Kod Fail Ini".
  2. Buka laman tiiny.host di browser anda.
  3. Simpan kod ini sebagai fail index.html dan muat naik (*drag & drop*).
  4. Anda akan terus dapat link URL seperti albaqarah.tiiny.site!
Cara Kekal Sepanjang Hayat:

Masukkan fail index.html ini ke dalam akaun GitHub Pages atau Vercel. Ia akan sentiasa percuma dan link tidak akan tamat tempoh.

Cara Letak Di Depan Skrin Telefon

Buka seperti Apps biasa!
Untuk Pengguna iPhone (Safari):
  1. Buka pautan laman ini di pelayar Safari.
  2. Tekan butang Share ( kotak beranak panah ke atas di bawah skrin).
  3. Skrol ke bawah dan pilih "Add to Home Screen" (Tambah ke Skrin Utama).
  4. Tekan Add di penjuru atas kanan.
Untuk Pengguna Android (Chrome):
  1. Buka pautan laman ini di Google Chrome.
  2. Tekan butang Menu 3 titik () di penjuru atas kanan.
  3. Pilih "Add to Home screen" atau "Install app".
  4. Tekan Add / Install.
